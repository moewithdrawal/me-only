# little wish ♡ — iPhone-first personal PWA

A free, editable starter project. It uses HTML, CSS and JavaScript, with local browser storage. No account, paid builder, external library, or backend is required for this first version.

## Files
- `index.html` — app, styles and features
- `manifest.webmanifest` — home-screen app metadata
- `sw.js` — basic offline cache

## Publish free with GitHub Pages (iPhone)
1. Sign in at https://github.com/ in Safari.
2. Create a new **public** repository named `little-wish`.
3. Use **Add file → Upload files** and upload all three files from this folder.
4. Commit the files.
5. Open repository **Settings → Pages**.
6. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
7. Wait for the published URL shown in Pages.
8. Open that URL in Safari → Share → Add to Home Screen.

## Important
- Your data is stored locally in the browser on this iPhone. Export backups regularly in Settings.
- Clearing Safari website data, deleting the web app's data, or losing the phone can erase local records. Keep backup files somewhere safe.
- The starter has expression PNG uploads, manual theme presets/custom colors, savings goals, transactions, recipes, journal entries, goals, daily quests and dashboard shortcuts.
- It does not yet have scheduled notifications, cloud sync, calendar integration, or a full custom button image editor.
- For the companion, upload transparent PNGs under 3 MB per expression. Assign an image to `idle`, `happy`, `excited`, `sleepy`, `sad`, `proud`, or `comfort`.
- iOS web push notifications require a separately hosted push service. This starter deliberately does not pretend local browser storage can send scheduled notifications.
